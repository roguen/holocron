# Third-party notices

Holocron is **GPL-3.0-or-later** (D-010). It builds against the libraries below.
Full licence texts are in [`licenses/`](licenses/), copied verbatim from the
packages actually installed by the pinned vcpkg baseline rather than transcribed
from upstream — so what is recorded here is what is genuinely linked.

This file is generated by hand and must be updated whenever `vcpkg.json` changes.
There is no CI check for it (issue #7 raised the notices; keeping them current is
still a human step).

## FFmpeg is LGPL, and that is a deliberate configuration

`vcpkg.json` pins FFmpeg with **`default-features: false`** and an explicit
feature list, so the port's `gpl` and `nonfree` features are excluded. Neither is
in the port's defaults today, but relying on an upstream default nobody here
controls is the wrong bet: **`nonfree` produces libraries that are
unredistributable under any licence**, which would be unfixable after the fact.

The result is LGPL-2.1-or-later, which is compatible with GPL-3.0-or-later, and
the licence text shipped in `licenses/` is the LGPL 2.1 as the package itself
provides it.

**On Windows FFmpeg is dynamically linked**, as `avcodec-62.dll`,
`avformat-62.dll`, `avutil-60.dll` and `swresample-6.dll` beside the executable.
That matters: the LGPL's requirement that a user be able to replace the library
with a modified version is satisfied by the DLL boundary itself, with nothing
further needed. `libebur128` and SDL3 ship the same way.

This was checked rather than assumed — an earlier reading of the Linux link line,
where vcpkg produces static archives, suggested static linking on both platforms.
It is static on Linux and shared on Windows, and Windows is the distribution
target (D-022).

## libprojectM is not here yet, and will need care when it is

D-012 requires libprojectM to stay **dynamically linked through its C API** to
keep the LGPL-2.1 §6(b) boundary intact. It is an M4 dependency and is
deliberately absent from `vcpkg.json`; it may not simply be added. When it lands,
this file and that boundary both need revisiting.

## What this file does not do

It does not reproduce the GPL-3.0 text for Holocron itself — that is
[`LICENSE`](LICENSE). It does not cover fonts, media or preset content, because
there are none. And it is not legal advice; it is a record of what is linked,
under what terms, and how.
